구글시트 업무 보드

구글시트 한 장을 업무 칸반 보드 · 캘린더 · 요약 차트로 바꿔 주는 파일 하나짜리 대시보드. 설치도 계정 연결도 없이, 브라우저로 열면 시트를 그대로 읽어 옵니다.

왜 만들었나

행이 늘면 안 보인다 시트가 50행을 넘어가면 “지금 내가 뭘 해야 하나”를 스크롤로 찾게 됩니다.
빈 열이 화면을 잡아먹는다 상태·마감 열이 비어 있으면 차트는 “미입력 100%”만 그립니다. 절반이 데이터 없음인 대시보드는 안 봅니다.
정작 중요한 건 메모에 있다 실무 정보는 “진행 현황” 열의 자유 텍스트에 쌓이는데, 그게 표에서 가장 안 보이는 칸입니다.
그래서 메모를 화면 앞으로.
차트가 아니라 카드가 주인공입니다. 클릭하지 않아도 태스크명과 최신 진행 메모가 보입니다.

설계 원칙

빈 칸을 오류로 보지 않는다 비어 있는 열은 미분류 · 미기입 · 미입력으로 집계할 뿐, 화면이 깨지지 않습니다. 시트를 완벽하게 채우지 않아도 오늘부터 씁니다.
시트를 건드리지 않는다 읽기 전용입니다. 대시보드를 잘못 눌러 원본이 바뀌는 일은 없습니다.
열 순서만 맞으면 된다 헤더 문구는 무엇이든 상관없습니다. A~L 열 순서만 지키면 다른 업무 시트에도 그대로 씁니다.

무소식 감지 메모의 [8/13] 날짜를 읽어 방치된 건을 찾아냅니다. 7일 이상 주황, 14일 이상 빨강. 마감일이 비어 있어도 위험을 볼 수 있는 유일한 신호입니다.
▤
캘린더 처리예정일자 · 처리일자 · 요청 일자 · 업데이트 기록 중 기준을 골라 월별로. 데이터가 가장 많은 기준을 자동 선택해 빈 화면을 보여주지 않습니다.
◈
업무일지 자동 작성 실적·계획 기간만 정하면 ① 상위 / - 하위 / > 세부 형식의 보고용 표를 만듭니다. 실적 행·계획 행이 위·아래로 같은 양식이라 엑셀에 그대로 붙여넣습니다.
＋
상태값 자동 반영 상태 목록을 코드에 고정하지 않습니다. 시트 드롭다운에 새 상태를 추가하면 KPI · 보드 열 · 필터 · 캘린더 범례에 자동으로 나타나며, 처음 보는 값에는 NEW 배지가 붙습니다.

어떻게 쓰나

  1. 시트를 링크 공개로 — 파일 → 공유 → 링크가 있는 모든 사용자(보기)
  2. 시트 ID 복사 — URL의 /d/ 와 /edit 사이
  3. 파일을 열 때 붙이기
    dashboard.html?sheet=시트ID

ID 없이 열면 데모 데이터로 실행되니, 먼저 화면부터 확인해 보세요. 시트 ID는 코드에 하드코딩하지 않습니다 — 저장소에 업무 데이터가 남지 않는 구조입니다.

알아 두실 점

브라우저가 시트를 직접 읽으므로 시트가 링크 공개 상태여야 합니다. 비공개 시트를 쓰려면 별도 백엔드나 Apps Script 프록시가 필요합니다. 필터·탭 상태는 새로고침하면 초기화됩니다.

업무 데이터를 커밋하지 마세요. 배포된 페이지 URL에 실제 시트 ID를 붙여 공유하는 것은 시트를 공개하는 것과 같습니다.
